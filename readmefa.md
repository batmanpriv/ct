## این ابزار دقیقا چیه و به چه دردی میخوره

خب، بذارین ساده بگم. فرض کنین که می‌خواین:

- بهترین دی‌ان‌اس رو پیدا کنین که سریع‌ترین باشه
- یه لیست پروکسی بزرگ رو چک کنین ببینین کدوم‌ها زنده‌ان
- کانفیگ‌های Xray یا V2Ray که دارین رو قبل از استفاده تست کنین
- آی‌پی‌های کلودفلر رو اسکن کنین برای راه‌اندازی تونل
- سورس‌های عمومی رو بگیرین و ازشون استفاده کنین

**CT** دقیقاً برای همین کارها ساخته شده. به جای اینکه برای هر کدوم از این کارا یه ابزار جداگانه نصب کنین و یاد بگیرین، همه‌ش رو توی یه فایل اجرایی جمع کردیم.

## چرا باید ازش استفاده کنم

چند تا دلیل خوب داره:

✅ **همه‌کاره‌ست**: دی‌ان‌اس، پروکسی، MTProto، Xray، کلودفلر اسکنر و اسکرپر، همه توی یه جا  
✅ **سریعه**: از چندین نخ (گوروتین) برای همزمان انجام دادن کارها استفاده می‌کنه  
✅ **راحت‌ه**: یه حالت تعاملی داره که با کلیدهای جهت‌دار کار می‌کنه، نیازی به حفظ کردن دستورات نیست  
✅ **رایگانه**: اوپن سورسه و هیچ هزینه‌ای نداره  
✅ **چند-سیستمعاملی**: روی ویندوز، لینوکس و مک کار می‌کنه  
✅ **خودش رو آپدیت می‌کنه**: یه سیستم آپدیت داره که آخرین نسخه رو برات نصب می‌کنه  
✅ **قابل اعتماده**: کدش تمیز و بهینه‌ست، با Go نوشته شده

## تازه های نسخه ۱.۵.۱

این نسخه یه قابلیت خیلی باحال داره که می‌تونه به کارت بیاد. حالا می‌تونی **کانفیگ پروکسی واقعی** (مثل VMess، VLESS، Trojan و Shadowsocks) رو روی آی‌پی‌های کلودفلر تست کنی.

**یعنی چی؟**

فرض کن یه کانفیگ V2Ray داری که توش یه آی‌پی یا دامنه گذاشتی. با این قابلیت جدید، CT می‌تونه این کانفیگ رو با آی‌پی‌های مختلف کلودفلر تست کنه و بهت بگه کدوم آی‌پی با کانفیگت کار می‌کنه. حتی می‌تونه کانفیگ نهایی رو با آی‌پی جدید برات ذخیره کنه.

**چه فرمت‌هایی رو پشتیبانی می‌کنه؟**
- VMess (`vmess://...`)
- VLESS (`vless://...`)
- Trojan (`trojan://...`)
- Shadowsocks (`ss://...`)
- لیست سابسکریپشن با فرمت base64

**چطوری کار می‌کنه؟**
۱. کانفیگت رو به CT می‌دی (یا مستقیم یا توی یه فایل)
۲. آی‌پی‌های کلودفلر رو اسکن می‌کنه
۳. هر آی‌پی که پیدا کنه، کانفیگت رو روش تست می‌کنه
۴. اگه کانفیگ کار کرد، بهت نشون می‌ده و ذخیره‌ش می‌کنه

## قابلیت ها به زبان ساده

### 🔍 تست دی‌ان‌اس (DNS Benchmark)

بهت کمک می‌کنه سریع‌ترین و بهترین دی‌ان‌اس رو پیدا کنی.

**چه کارایی می‌تونه بکنه؟**
- یه لیست دی‌ان‌اس بهش بدی، همه رو تست می‌کنه
- سرعت هر کدوم رو اندازه می‌گیره
- بهت امتیاز می‌ده (از ۰ تا ۱۰۰)
- می‌تونه بهترین رو به صورت خودکار روی سیستمت تنظیم کنه
- از UDP، TCP، DNS-over-TLS و DNS-over-HTTPS پشتیبانی می‌کنه

### 🌐 چک کردن پروکسی (Proxy Checker)

لیست پروکسی‌های HTTP، HTTPS، SOCKS4 و SOCKS5 رو چک می‌کنه.

**چه کارایی می‌تونه بکنه؟**
- تشخیص خودکار نوع پروکسی
- تست همزمان برای سرعت بالا
- بهت می‌گه کدوم پروکسی‌ها زنده‌ان
- بهترین پروکسی رو می‌تونه روی سیستم اعمال کنه

### 📱 تست MTProto (پروکسی تلگرام)

پروکسی‌های مخصوص تلگرام رو تست می‌کنه.

**چه کارایی می‌تونه بکنه؟**
- لینک‌های تلگرام (`tg://`) رو پشتیبانی می‌کنه
- سرعت و تأخیر رو اندازه می‌گیره
- پروکسی‌های معتبر رو توی فایل ذخیره می‌کنه

### ⚡ تست کانفیگ Xray و V2Ray

کانفیگ‌های VLESS، VMESS، Trojan و Shadowsocks رو تست می‌کنه.

**چه کارایی می‌تونه بکنه؟**
- ترانسپورت‌های مختلف (WebSocket، gRPC، HTTPUpgrade) رو پشتیبانی می‌کنه
- TLS و Reality رو هندل می‌کنه
- کانفیگ‌های تکراری رو حذف می‌کنه
- موقعیت جغرافیایی رو تشخیص می‌ده
- کانفیگ‌های زنده رو توی فایل ذخیره می‌کنه

### ☁️ اسکن آی‌پی کلودفلر (Cloudflare Scanner)

آی‌پی‌های کلودفلر رو اسکن می‌کنه و آی‌پی‌های کاری رو پیدا می‌کنه.

**چه کارایی می‌تونه بکنه؟**
- اسکن سریع با چندین نخ همزمان
- تشخیص خودکار کلودفلر از طریق هدرها و گواهی‌ها
- پشتیبانی از HTTP/2 و HTTP/3
- اندازه‌گیری تأخیر با رنگ‌بندی
- ذخیره لحظه‌ای آی‌پی‌های پیدا شده
- خروجی‌های مختلف (JSON، CSV، TXT)
- اسکن رنج‌های سفارشی

### 📡 اسکرپر (Scraper)

از سورس‌های مختلف لیست پروکسی و کانفیگ می‌گیره.

**چه کارایی می‌تونه بکنه؟**
- افزودن و حذف سورس
- بارگذاری مجدد کانفیگ
- نمایش سورس‌های فعال
- اجرای مستقیم اسکرپ

## چطور ازش استفاده کنم

### تست دی‌ان‌اس (DNS)

**ساده‌ترین روش:**
```bash
ct dns resolvers.txt
```

**با تست HTTP برای دقت بیشتر:**
```bash
ct dns resolvers.txt -mode 1 -domains "cloudflare.com,google.com,github.com"
```

**پیدا کردن و اعمال بهترین دی‌ان‌اس:**
```bash
ct dns apply-best
```

**مشاهده دی‌ان‌اس فعلی سیستم:**
```bash
ct dns status
```

---

### چک کردن پروکسی

**ساده‌ترین روش:**
```bash
ct proxy proxies.txt
```

**با تنظیم تعداد نخ‌ها (برای سرعت بیشتر):**
```bash
ct proxy proxies.txt -threads 100
```

**دانلود پروکسی از سورس‌های عمومی:**
```bash
ct proxy download
```

**اسکرپ پروکسی:**
```bash
ct proxy scrape
```

**اعمال بهترین پروکسی روی سیستم:**
```bash
ct proxy apply-best
```

**تست لیست پروکسی:**
```bash
ct mtproto mtproto.txt
```

**دانلود پروکسی از سورس‌های عمومی:**
```bash
ct mtproto download
```

**تست کانفیگ‌ها:**

**دانلود کانفیگ از سورس‌های عمومی:**

### اسکن آی‌پی کلودفلر

**اسکن ساده با تنظیمات پیش‌فرض:**
```bash
ct cf scan
```

**اسکن با ۲۰۰ نخ و پورت‌های خاص:**
```bash
ct cf scan -workers 200 -ports 443,8443,2096
```

**اسکن رنج‌های کامل کلودفلر (کندتر ولی کامل‌تر):**
```bash
ct cf scan -source cloudflare_all
```

**اسکن از فایل آی‌پی سفارشی:**
```bash
ct cf scan -source custom:ips.txt
```

**ذخیره نتایج به صورت CSV:**
```bash
ct cf scan -format csv -output scan.csv
```

**مرتب‌سازی بر اساس تأخیر:**
```bash
ct cf scan -sort latency
```

**غیرفعال کردن نمایش لحظه‌ای (برای اسکریپت‌ها):**
```bash
ct cf scan -quiet
```

## تست کانفیگ پروکسی (قابلیت جدید)

این قابلیت جدید بهت کمک می‌کنه کانفیگ پروکسی‌های واقعی رو روی آی‌پی‌های کلودفلر تست کنی.

### چطوری کار می‌کنه؟

فرض کن یه کانفیگ V2Ray داری که توش یه سرور نوشته شده. CT می‌تونه این کانفیگ رو با آی‌پی‌های مختلف کلودفلر تست کنه و بهت بگه کدوم آی‌پی با کانفیگت کار می‌کنه.

### تست یک کانفیگ

```bash
ct cf scan -config "vmess://eyJhZGQiOiJleGFtcGxlLmNvbSIsInBvcnQiOiI0NDMiLCJpZCI6InV1aWQtaGVyZSJ9"
```

### تست کانفیگ از فایل

```bash
ct cf scan -config configs.txt -workers 300 -stop-after 10
```

این دستور تا وقتی که ۱۰ تا کانفیگ کاری پیدا کنه، اسکن رو ادامه می‌ده.

### ذخیره کانفیگ‌های کاری

```bash
ct cf scan -config "trojan://password@example.com:443?security=tls&sni=example.com" -output working_configs.json
```

**خروجی‌هایی که تولید می‌شه:**
- `config_tested_ips_YYYYMMDD_HHMMSS.txt` — همه آی‌پی:پورت‌هایی که تست شدن
- `config_tested_success_YYYYMMDD_HHMMSS.txt` — کانفیگ‌های کاری با آی‌پی جایگزین شده (آماده برای استفاده!)

### تنظیمات پیشرفته تست کانفیگ

```bash
# تغییر تایم‌اوت تست کانفیگ
ct cf scan -config "vmess://..." -config-test-timeout 15

# غیرفعال کردن سابنت خودکار
ct cf scan -config "vmess://..." -no-auto-subnet

# تنظیم طول سابنت
ct cf scan -config "vless://uuid@1.2.3.4:443" -subnet-prefix 24
```

## مشکلات رایج و راه حل ها

### ۱. ارور `go: command not found`

اگه این ارور رو گرفتی، یعنی Go روی سیستمت نصب نیست.

**راه حل:**
- از [golang.org](https://golang.org/dl/) Go رو نصب کن
- یا از روش سوم نصب (دانلود باینری) استفاده کن

### ۲. اسکن کلودفلر کند کار می‌کنه

اگه اسکن کلودفلر کند شد، می‌تونی تعداد نخ‌ها رو زیاد کنی.

**راه حل:**
```bash
ct cf scan -workers 500
```
(البته زیاده‌روی نکن، اگه خیلی زیاد بشه ممکنه ISP یا فایروالت مشکل ایجاد کنه)

### ۳. تست کانفیگ خطا می‌ده

اگه `-config` خطا داد، چند تا چیز رو چک کن:

**راه حل:**
- فرمت کانفیگ رو چک کن (VMess، VLESS، Trojan، SS)
- تایم‌اوت رو زیاد کن: `-config-test-timeout 15`
- سابنت خودکار رو غیرفعال کن: `-no-auto-subnet`
- پورت کانفیگ رو به لیست پورت‌ها اضافه کن: `-ports 443,80,2087`

### ۴. حالت تعاملی درست کار نمی‌کنه

اگه منوی تعاملی درست نمایش داده نمی‌شه:

**راه حل:**
- ترمینالت رو بزرگتر کن
- از ترمینال استاندارد (نه Powershell قدیمی) استفاده کن
- مطمئن شو ترمینالت از رنگ‌های ANSI پشتیبانی می‌کنه

### ۵. آپدیت کار نمی‌کنه

اگه `ct check-update` خطا داد:

**راه حل:**
- مطمئن شو Go نصب هست
- مطمئن شو Git نصب هست
- اگه روی ویندوزی، مطمئن شو فایروال اجازه دانلود می‌ده
- می‌تونی دستی آخرین نسخه رو از GitHub دانلود کنی

## سوالات متداول

**س: CT با چه زبانی نوشته شده؟**

ج: با زبان Go (گولنگ) نوشته شده. به خاطر همین سریع و سبکه.

**س: چقدر حافظه مصرف می‌کنه؟**

ج: خیلی کم، معمولاً کمتر از ۵۰ مگابایت. اگه با تعداد نخ‌های بالا اسکن کنی، ممکنه تا ۱۰۰-۲۰۰ مگابایت بره بالا.

**س: می‌تونم ازش توی اسکریپت‌ها استفاده کنم؟**

ج: بله، همه دستورات خروجی استاندارد دارن و می‌تونی خروجی رو به فایل یا پایپ کنی. پرچم `-quiet` هم برای اسکریپت‌ها داره.

**س: چقدر ترافیک مصرف می‌کنه؟**

ج: خود CT ترافیک زیادی مصرف نمی‌کنه، فقط برای تست‌ها. مثلاً اسکن کلودفلر ممکنه چند مگابایت ترافیک مصرف کنه.

**س: می‌تونم با CT پروکسی بسازم؟**

ج: خود CT یه ابزار تست و اسکنه، نه سرور پروکسی. ولی می‌تونه بهت کمک کنه بهترین آی‌پی‌ها و کانفیگ‌ها رو پیدا کنی تا با ابزارهای دیگه (مثل Xray یا V2Ray) استفاده کنی.

**س: آیا CT از IPv6 پشتیبانی می‌کنه؟**

ج: بله، هم برای تست دی‌ان‌اس و هم برای اسکن کلودفلر، IPv6 رو پشتیبانی می‌کنه.

**س: چطور می‌تونم به پروژه کمک کنم؟**

ج: خیلی راحت! می‌تونی باگ‌ها رو گزارش بدی، پیشنهاد قابلیت جدید بدی، یا کد رو فورک کنی و Pull Request بفرستی. همه کمک‌ها خوش‌آمدن!

## جمع بندی نهایی

CT یه ابزار همه‌کاره‌ست که می‌تونه خیلی از کارهای روزمره شبکه رو برات انجام بده. چه بخوای بهترین دی‌ان‌اس رو پیدا کنی، چه بخوای پروکسی‌ها رو چک کنی، چه بخوای آی‌پی کلودفلر اسکن کنی یا کانفیگ‌های Xray رو تست کنی، این ابزار به کمکت میاد.

**پیشنهاد من:** اول با `ct interactive` شروع کن و گزینه‌ها رو ببین. بعد که با کاراش آشنا شدی، می‌تونی از دستورات مستقیم توی اسکریپت‌هات استفاده کنی.
